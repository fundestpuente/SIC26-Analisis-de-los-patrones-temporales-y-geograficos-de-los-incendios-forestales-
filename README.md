## 📝 Descripción del Proyecto
Este proyecto busca analizar los incendios forestales registrados en Ecuador mediante Python y herramientas de análisis de datos.

A partir de información publicada por instituciones oficiales, se pretende identificar patrones temporales y geográficos, como los períodos y provincias con mayor afectación, además de estudiar la superficie de vegetación afectada.

El objetivo es transformar los datos históricos en gráficos y estadísticas que permitan comprender mejor el comportamiento de los incendios forestales y contribuir a la prevención y gestión de riesgos ambientales.

Fuentes de datos:

- Secretaría Nacional de Gestión de Riesgos.

- Portal de Datos Abiertos del Ecuador.

- Ministerio del Ambiente, Agua y Transición Ecológica.

### 🪜 Pasos de Ejecución

   ```bash

   ```

2. Instalar dependencias:
   ```bash
   pip install -r requirements.txt
      ```

3. Abrir el notebook principal:
   ```bash
   jupyter notebook main.ipynb
      ```
   o directamente desde VS Code con la extensión de Jupyter.
